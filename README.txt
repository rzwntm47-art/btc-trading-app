V17 Installable PWA. Upload all files together to an HTTPS static host (for example GitHub Pages, Cloudflare Pages or Netlify). Visit its HTTPS URL in Android Chrome and use Chrome menu > Add to Home screen > Install. Opening index.html from Downloads/content:// does NOT enable PWA installation or service workers. Market prices require network. Browser suspension stops trading. No real orders. Do not put API secrets in this project.
